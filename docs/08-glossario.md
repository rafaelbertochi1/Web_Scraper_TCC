# 08 — Glossário

| Termo | Definição |
|-------|-----------|
| **Web scraping** | Técnica de extração automatizada de dados de páginas web |
| **Scraper / coletor** | Programa que realiza o web scraping de uma fonte |
| **Crawler** | Programa que navega entre páginas seguindo links |
| **`robots.txt`** | Arquivo em que o site indica quais caminhos robôs podem acessar |
| **Rate limiting** | Limitação da frequência de requisições feitas a um servidor |
| **Backoff exponencial** | Estratégia de novas tentativas com intervalos crescentes |
| **Página dinâmica** | Página cujo conteúdo é gerado por JavaScript no navegador |
| **ETL** | _Extract, Transform, Load_ — extração, transformação e carga de dados |
| **DDL** | _Data Definition Language_ — comandos SQL que definem estruturas (`CREATE TABLE`) |
| **ADR** | _Architecture Decision Record_ — registro de decisão de arquitetura |
| **LGPD** | Lei Geral de Proteção de Dados (Lei nº 13.709/2018) |
| **Área útil** | Área interna privativa do imóvel, sem paredes externas e áreas comuns |
| **Área total** | Área privativa somada à fração de áreas comuns |
| **Preço por m²** | Preço do imóvel dividido pela área (geralmente útil) |
| **Condomínio** | Taxa mensal para manutenção das áreas comuns |
| **IPTU** | Imposto Predial e Territorial Urbano |
| **ITBI** | Imposto sobre Transmissão de Bens Imóveis |
| **Rentabilidade bruta (_rental yield_)** | Aluguel anual ÷ preço de venda |
| **Índice FipeZAP** | Índice de referência de preços de imóveis anunciados no Brasil |
