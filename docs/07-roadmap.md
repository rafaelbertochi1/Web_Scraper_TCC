# 07 — Roadmap

> Datas a definir de acordo com o calendário do TCC.

| Fase | Entregas | Status |
|------|----------|:------:|
| **0. Planejamento** | Estrutura do repositório, documentação inicial, definição de escopo | 🟡 Em andamento |
| **1. Levantamento de fontes** | Avaliação de fontes (termos de uso, `robots.txt`, viabilidade), escolha do recorte geográfico | ⚪ Pendente |
| **2. Protótipo de coleta** | Scraper de uma fonte, extraindo os campos obrigatórios; testes com HTML de exemplo | ⚪ Pendente |
| **3. Banco de dados** | Esquema SQL versionado, carga dos dados coletados, controle de execuções | ⚪ Pendente |
| **4. ETL e qualidade** | Limpeza, padronização, validação, deduplicação e logs | ⚪ Pendente |
| **5. Expansão** | Novas fontes, coleta periódica agendada, acúmulo de histórico | ⚪ Pendente |
| **6. Análise** | Consultas SQL analíticas, notebooks, gráficos e indicadores | ⚪ Pendente |
| **7. Escrita e entrega** | Consolidação dos resultados no texto do TCC, revisão da documentação | ⚪ Pendente |

## Trabalhos futuros (fora do escopo inicial)

- Modelo preditivo de preços (regressão / _machine learning_);
- Painel interativo (ex.: Streamlit ou Metabase);
- Geolocalização e análise espacial com mapas;
- Detecção de anúncios duplicados entre fontes diferentes.
