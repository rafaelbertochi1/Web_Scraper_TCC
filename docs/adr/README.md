# Registros de Decisões de Arquitetura (ADRs)

Cada decisão técnica relevante do projeto é registrada em um arquivo curto e numerado, com contexto, decisão e consequências. Isso ajuda a justificar escolhas na banca do TCC.

## Como criar um novo ADR

1. Copie o [modelo](0000-modelo.md) para `NNNN-titulo-curto.md` (próximo número disponível);
2. Preencha as seções;
3. Adicione uma linha no índice abaixo.
